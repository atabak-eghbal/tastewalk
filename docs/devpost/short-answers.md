# What are you hoping to get out of this hackathon?
I want to build an agent that truly depends on Qloo's taste graph, ship it as a live, open-source app, and learn where cultural intelligence makes the biggest practical difference over LLM-only approaches.

# Project idea (short)
TasteWalk is a multi-agent app that uses Qloo's taste graph to turn a person's favorite music, films, and restaurants into a personalized walking itinerary for a city. It shows a side-by-side comparison with an LLM-only plan, so the Qloo-powered route, with "why this stop fits you" explanations, clearly stands out.
